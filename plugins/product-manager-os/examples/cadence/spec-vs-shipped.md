## The drifted gaps (the real finding)
- **Req 6 — dismissal doesn't feed back.** The dismissal *event* shipped, so every dashboard shows the feature working. **Why it went unnoticed:** the ticket was titled "add dismiss button," which was completed honestly; the learning half lived only in the spec prose and never became its own ticket. **Prevention:** every requirement with two verbs becomes two tickets.
- **Req 8 — empty state.** **Why it went unnoticed:** it only appears when nothing is detected, which never happens in a seeded test account. **Prevention:** add "what does this look like with zero data" to the test-scenarios checklist.
- **The Slack DM addition.** **Why it went unnoticed:** non-goals were in the spec but not in the PR template, so no reviewer was prompted to check against them. **Prevention:** add "does this break a stated non-goal?" to the PR checklist.
